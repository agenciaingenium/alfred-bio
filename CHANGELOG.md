# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-06-14

### Added
- GitHub Actions workflow for automatic deployment to GitHub Pages
- Open Graph and meta tags for social media previews
- HTML linting with htmlhint in CI
- Changelog for version tracking
- README with project documentation

### Changed
- Improved data.json structure for dynamic content

## [0.1.4] - 2026-02-14

### Added
- Initial public release
- Dynamic stats from data.json
- AI usage visualization
- Agent status display
- Activity log
